# Instalação do Node no Windows (padrão recomendado)

Este projeto foi ajustado para rodar com **Tailwind v3** (mais compatível) e instalação estável.

## Versão recomendada
- **Node.js LTS** (18 ou 20)
- NPM que vem junto

## Verificar no terminal (PowerShell)
```powershell
node -v
npm -v
```

## Se não existir Node no PATH
Instale o Node LTS e feche/abra o VS Code.

## Instalação estável (recomendada)
Na raiz do projeto:
- `bats\Dependencias\01_instalar_dependencias_estavel.bat`

Depois:
- `npm run dev`
